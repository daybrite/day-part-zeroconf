# day-part-zeroconf

Discover and advertise services on the local network.

[Day](https://daybrite.dev/docs/) is a Rust framework for building apps with native desktop and
mobile controls, plus HTML controls on the web.

Browse, resolve, register, and query DNS-SD services through native APIs. Transport,
authentication, and service trust remain the app’s responsibility.

## Use

Add `day-part-zeroconf = "0.*"` to your app’s `[dependencies]`.
Follow the setup guide for platform requirements and initialization.
